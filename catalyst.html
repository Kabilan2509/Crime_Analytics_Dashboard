Karnataka State Police (KSP)

Crime Analytics & Intelligence Platform — Zoho Catalyst Services Audit

Document ID: KSP-CATALYST-AUDIT-2026
Platform: Zoho Catalyst Suite
Status: Active Production Infrastructure

This document presents a comprehensive audit of all Zoho Catalyst Cloud Services currently operational within the Karnataka State Police Crime Analytics Dashboard, along with the strategic roadmap of upcoming Catalyst services for full state-wide deployment.

1. Active Zoho Catalyst Services (Currently Implemented)

Catalyst Service Category Implementation & Technical Scope Status
Catalyst Data Store Relational Database Houses all 26 relational database tables containing 1,501 FIR records, accused profiles, victim datasets, arrest sheets, police stations, and officer master tables. Active
ZCQL Engine Query Language Executes dynamic SQL relational joins, date-range filters, and aggregate counts (COUNT, SUM, GROUP BY) inside function endpoints. Active
Serverless Functions Node.js Express API Powers the central backend (crime_api) for pre-computed statistics, cache management, and AI copilot message routing. Active
Web Client Hosting Cloud Hosting Serves the single-page React client application with optimized single-command CLI deployment (catalyst deploy). Active
QuickML & GLM-4.7-Flash AI & Machine Learning Powers the MADHUKAR AI Copilot for natural language tool calling and automated executive briefings, plus a Random Forest model for crime risk scoring. Active
OAuth & Credential Vault Auth Security Multi-strategy authentication pipeline resolving Zoho OAuth tokens (QuickML.deployment.READ) for secure SDK and REST communications. Active

2. Recommended Future Catalyst Services (Expansion Roadmap)

Catalyst Service Targeted Feature Operational Impact & Value Proposition Priority
Catalyst Authentication Role-Based Access (RBAC) Enforce rank-based access control (Commissioner vs. District SP vs. Station IO) with secure OTP & SSO login. High
Catalyst File Store Digital Evidence Vault Upload and preview case document PDFs, scanned FIR papers, weapon photos, charge-sheets, and crime scene images. High
Catalyst Zia AI OCR & Text NLP Analysis Auto-extract text from handwritten police complaints using Zia OCR, and auto-parse suspect names/locations from narrative text using Zia NLP. Medium
Catalyst Cron Jobs Automated Nightly Tasks Run background jobs at 00:00 UTC to recalculate risk scores, aggregate station workloads, and generate daily executive summaries. Medium
Push Notifications Real-Time Heinous Crime Alerts Dispatch immediate SMS/Push alerts to District SPs whenever a grave offence (e.g. Murder, Robbery) or repeat offender is registered. Medium
Catalyst Cache In-Memory Redis Cache Upgrade the local Node memory cache to distributed Catalyst Cache for sub-millisecond database queries across all function instances. Low
